# MyAgent - কোম্পানি এআই এজেন্ট ও পারসিসটেন্ট নলেজ মেমোরি প্ল্যাটফর্ম

[![Docker](https://img.shields.io/badge/Docker-24.0+-blue.svg)](https://www.docker.com/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.110+-green.svg)](https://fastapi.tiangolo.com/)
[![ChromaDB](https://img.shields.io/badge/ChromaDB-Vector_Memory-purple.svg)](https://www.trychroma.com/)
[![Architecture](https://img.shields.io/badge/Architecture-OpenClaw_Style_Agent-orange.svg)]()

সার্ভার **`192.168.9.9`**-এ ডিপ্লয় করার জন্য প্রস্তুত একটি সম্পূর্ণ স্বাধীন, প্রাইভেট এবং ডকারাইজড কোম্পানি এআই এজেন্ট রিপোজিটরি। এই এজেন্টটি কোম্পানির নিজস্ব ফাইল ও ডেটা (PDF, Word, Excel/CSV, Text, Markdown) বিশ্লেষণ করে নিজস্ব ভেক্টর মেমোরিতে সংরক্ষণ করে এবং বাহ্যিক এলএলএম সার্ভারের (যেমন: Ollama, vLLM, LM Studio, বা ক্লাউড API) সাথে যুক্ত হয়ে ওপেনক্ল (OpenClaw) স্টাইলে সিদ্ধান্ত ও উত্তর প্রদান করে।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

- 🔒 **১০০% নিজস্ব কোম্পানি ডেটা প্রাইভেসি:** সমস্ত কোম্পানি ডকুমেন্ট ও মেমোরি সার্ভারের ভেতরের ChromaDB ভেক্টর ডাটাবেজে সংরক্ষিত থাকে।
- 🌐 **ওপেনক্ল-স্টাইল ওয়েব ইন্টারফেস:** প্রিমিয়াম ডার্ক-মোড ইন্টারফেস, রিয়েলটাইম স্ট্রিমিং চ্যাট, ড্র্যাগ-অ্যান্ড-ড্রপ ডকুমেন্ট আপলোডার এবং মেমোরি এক্সপ্লোরার।
- 🧠 **স্বয়ংসম্পূর্ণ ভেক্টর মেমোরি (RAG):** মাল্টি-ফরম্যাট ফাইল পার্সিং (PDF, DOCX, TXT, CSV, JSON) এবং অটোমেটিক সেমান্টিক রিট্রিভাল।
- 🔌 **যেকোনো এলএলএম সার্ভারের সাথে সংযোগ:** OpenAI-সামঞ্জস্যপূর্ণ প্রোটোকল সমর্থন করে (Ollama, vLLM, LM Studio, DeepSeek, Llama 3.3, Qwen 2.5 ইত্যাদি)।
- 🚀 **১-ক্লিক ডিপ্লয়মেন্ট:** লিনাক্স এবং উইন্ডোজ উভয় ডকার হোস্টে এক ক্লিকেই ডিপ্লয়মেন্ট সম্ভব।

## 🚀 সার্ভার ১৯২.১৬৮.৯.৯-এ ইনস্টলেশন নির্দেশিকা (Deployment Guide)

### ধাপ ১: রিপোজিটরি সার্ভারে কপি বা ক্লোন করুন
সার্ভার `192.168.9.9`-এ লগইন করে রিপোজিটরি ফোল্ডারে প্রবেশ করুন:
```bash
git clone <YOUR_REPOSITORY_URL> myagent
cd myagent
```

### ধাপ ২: এনভায়রনমেন্ট কনফিগারেশন (`.env`)
প্রয়োজনে `.env` ফাইলে আপনার এলএলএম সার্ভারের আইপি ও মডেলের নাম উল্লেখ করুন:
```bash
cp .env.example .env
nano .env
```
কনফিগারেশন উদাহরণ:
```ini
WEB_PORT=3000
BACKEND_PORT=8000

# আপনার বাহ্যিক এলএলএম সার্ভারের আইপি ও পোর্ট (যেমন Ollama)
LLM_BASE_URL=http://192.168.9.10:11434/v1
LLM_MODEL=llama3.3
LLM_API_KEY=not-needed

AGENT_NAME="Company Data Intelligence Agent"
```

### ধাপ ৩: ডিপ্লয়মেন্ট স্ক্রিপ্ট রান করুন (১-ক্লিক ইনস্টল)
```bash
chmod +x deploy.sh
./deploy.sh
```

*(উইন্ডোজ ডকার ডেস্কটপ ব্যবহারকারীদের জন্য: PowerShell-এ `.\deploy.ps1` চালান)*

## 🖥️ ব্যবহার প্রণালী (How to Use)

### ১. ওয়েব ইন্টারফেসে প্রবেশ
আপনার ব্রাউজার ওপেন করে প্রবেশ করুন:
👉 **`http://192.168.9.9:3000`**

### ২. এলএলএম সার্ভার টেস্ট
- সাইডবারের **"এলএলএম সেটিংস"** বাটনে ক্লিক করুন।
- আপনার এলএলএম সার্ভারের URL এবং মডেল দিন।
- **"সার্ভার সংযোগ টেস্ট করুন"** বাটনে চাপ দিয়ে ইনস্ট্যান্ট স্ট্যাটাস যাচাই করুন।

### ৩. কোম্পানি ডকুমেন্ট মেমোরিতে যুক্ত করা
- **"মেমোরি ও ডকুমেন্টস"** ট্যাবে ক্লিক করুন।
- কোম্পানির যেকোনো ফাইল (যেমন: `Company_Policy.pdf`, `Sales_Report.docx`, `Product_List.csv`) ড্র্যাগ-অ্যান্ড-ড্রপ করুন।
- ফাইলটি স্বয়ংক্রিয়ভাবে চাঙ্কিং এবং ChromaDB ভেক্টর ডাটাবেজে এমবেড হয়ে যাবে।

### ৪. এজেন্টের সাথে চ্যাট ও রিজনিং
- **"এআই চ্যাট"** ট্যাবে গিয়ে যেকোনো প্রশ্ন করুন।
- এজেন্ট স্বয়ংক্রিয়ভাবে মেমোরি থেকে প্রাসঙ্গিক তথ্য খুঁজে বের করবে এবং সোর্স ডকুমেন্ট রেফারেন্স সহ সঠিক উত্তর দেবে।

## 📡 REST API এন্ডপয়েন্টস

| মেথড | এন্ডপয়েন্ট | বিবরণ |
| :--- | :--- | :--- |
| `POST` | `/api/chat/stream` | রিয়েলটাইম এসএসই (SSE) স্ট্রিমিং চ্যাট |
| `POST` | `/api/chat` | স্ট্যান্ডার্ড চ্যাট রেসপন্স |
| `POST` | `/api/documents/upload` | কোম্পানি ফাইল আপলোড ও মেমোরি ইনডেক্সিং |
| `GET` | `/api/documents` | ইনডেক্স করা সকল ডকুমেন্টের তালিকা |
| `DELETE` | `/api/documents/{doc_id}` | মেমোরি থেকে ডকুমেন্ট ও ভেক্টর অপসারণ |
| `POST` | `/api/memory/search` | ডিরেক্ট সেমান্টিক ভেক্টর সার্চ |
| `POST` | `/api/memory/note` | সরাসরি কর্পোরেট মেমোরি নোট সংরক্ষণ |
| `GET` | `/api/settings` | অ্যাক্টিভ কনফিগারেশন পরিদর্শন |
| `POST` | `/api/settings/test-connection` | এলএলএম সার্ভার কানেকশন টেস্ট |
| `GET` | `/api/health` | ডকার কন্টেইনার হেলথচেক |

স্বয়ংক্রিয় সোয়াগার ডকুমেন্টেশন: **`http://192.168.9.9:8000/docs`**
