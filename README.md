# MyAgent - কোম্পানি এআই এজেন্ট ও পারসিসটেন্ট নলেজ মেমোরি প্ল্যাটফর্ম

[![Docker](https://img.shields.io/badge/Docker-Port_3399-blue.svg)](https://www.docker.com/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.110+-green.svg)](https://fastapi.tiangolo.com/)
[![ChromaDB](https://img.shields.io/badge/ChromaDB-Vector_Memory-purple.svg)](https://www.trychroma.com/)
[![Security](https://img.shields.io/badge/Security-Admin_Auth_Active-red.svg)]()

সার্ভার **`192.168.9.9:3399`**-এ ডিপ্লয় করার জন্য প্রস্তুত একটি সম্পূর্ণ স্বাধীন, প্রাইভেট এবং ডকারাইজড কোম্পানি এআই এজেন্ট রিপোজিটরি। এই এজেন্টটি কোম্পানির নিজস্ব ফাইল ও স্প্রেডশিট (PDF, Word, Excel .xlsx/.xls, CSV, Text, Markdown) বিশ্লেষণ করে নিজস্ব ভেক্টর মেমোরিতে সংরক্ষণ করে এবং বাহ্যিক এলএলএম সার্ভারের (যেমন: Ollama, vLLM, LM Studio, বা ক্লাউড API) সাথে যুক্ত হয়ে ওপেনক্ল (OpenClaw) স্টাইলে সঠিক সিদ্ধান্ত ও উত্তর প্রদান করে।

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

- 🔒 **অ্যাডমিন প্রমাণীকরণ (JWT Auth):** অননুমোদিত ব্যবহারকারীদের প্রবেশাধিকার বন্ধ রাখতে সিকিউর লগইন সিস্টেম (`admin / Aa987654`)।
- 💬 **স্থায়ী মাল্টি-সেশন চ্যাট হিস্টোরি:** SQLite ভিত্তিক পারসিসটেন্ট ডাটাবেজ। ব্রাউজার রিলোড দিলেও পূর্ববর্তী সমস্ত চ্যাট সুরক্ষিত থাকে।
- 📊 **এক্সেল স্প্রেডশিট ও ফিন্যান্সিয়াল ডাটা ইনজেস্ট:** `.xlsx` এবং `.xls` ফাইলের প্রতিটি সারি ও কলাম সম্পর্কভিত্তিক চাঙ্কিংয়ের মাধ্যমে নির্ভুল হিসাব প্রদান।
- 🌐 **ওপেনক্ল-স্টাইল ওয়েব ইন্টারফেস:** আধুনিক ডার্ক-মোড, রিয়েলটাইম এসএসই (SSE) স্ট্রিমিং, সোর্স রেফারেন্স সাইটেশন এবং ডায়নামিক মডেল সিলেক্টর ড্রপডাউন।
- 🔍 **ডকুমেন্ট চাঙ্ক ইন্সপেক্টর:** কোন ফাইলের কি কি টেক্সট চাঙ্ক ও ভেক্টর মেমোরিতে সংরক্ষিত আছে তা ওয়েব থেকে সরাসরি দেখার সুবিধা।
- 🧠 **১০০% লোকাল ভেক্টর মেমোরি (ChromaDB):** কোম্পানি ডেটা সম্পূর্ণ প্রাইভেট ও স্থানীয় সার্ভারে বিচ্ছিন্ন থাকে।
- 🚀 **১-ক্লিক অটোমেটেড ডিপ্লয়মেন্ট:** লিনাক্স ও উইন্ডোজ ডকার হোস্টের জন্য সম্পূর্ণ তৈরি।

## 🖥️ ব্যবহার প্রণালী (How to Use)

### ১. ওয়েব ইন্টারফেসে লগইন
ব্রাউজারে প্রবেশ করুন:
👉 **`http://192.168.9.9:3399`**
লগইন স্ক্রিনে দিন:
- ইউজারনেম: `admin`
- পাসওয়ার্ড: `Aa987654`

### ২. এলএলএম মডেল ও সার্ভার পরিবর্তন
- টপবারের মডেল ড্রপডাউন থেকে সরাসরি মডেল পরিবর্তন করুন।
- অথবা সাইডবারের **"এলএলএম সেটিংস"**-এ গিয়ে আপনার বাহ্যিক এলএলএম সার্ভারের আইপি (যেমন: `http://192.168.9.10:11434/v1`) কনফিগার করুন।

### ৩. কোম্পানি ডকুমেন্ট ও এক্সেল শিট আপলোড
- **"মেমোরি ও ডকুমেন্টস"** মেন্যুতে যান।
- কোম্পানির ফাইল (PDF, Word, Excel `.xlsx`, CSV, TXT) ড্র্যাগ করুন।
- ইনডেক্স হওয়া ফাইলের পাশে **"চাঙ্কস দেখুন"** বাটনে ক্লিক করে ভেক্টর মেমোরির সংরক্ষিত অংশগুলো দেখে নিন।

### ৪. মাল্টি-সেশন এআই চ্যাট
- **"এআই চ্যাট"** ট্যাবে গিয়ে প্রশ্ন করুন।
- বাম পাশের সাইডবারে যেকোনো সময় **"+"** চেপে নতুন চ্যাট সেশন খুলুন বা পুরনো চ্যাটে ফিরে যান।

## 📡 REST API এন্ডপয়েন্টস

| মেথড | এন্ডপয়েন্ট | বিবরণ |
| :--- | :--- | :--- |
| `POST` | `/api/auth/login` | অ্যাডমিন লগইন ও JWT টোকেন ইস্যু |
| `GET` | `/api/auth/verify` | টোকেন ভ্যালিডেশন |
| `GET` | `/api/sessions` | চ্যাট সেশনসমূহের তালিকা |
| `POST` | `/api/sessions` | নতুন চ্যাট সেশন তৈরি |
| `GET` | `/api/sessions/{id}` | সেশনের সমস্ত মেসেজ হিস্টোরি |
| `DELETE` | `/api/sessions/{id}` | চ্যাট সেশন মুছে ফেলা |
| `POST` | `/api/chat/stream` | রিয়েলটাইম এসএসই (SSE) চ্যাট স্ট্রিমিং |
| `POST` | `/api/documents/upload` | PDF/DOCX/XLSX/CSV ফাইল আপলোড ও মেমোরি ইনজেস্ট |
| `GET` | `/api/documents/{doc_id}/chunks` | ডকুমেন্টের সংরক্ষিত ভেক্টর চাঙ্কস প্রিভিউ |
| `POST` | `/api/memory/search` | সরাসরি ভেক্টর মেমোরি সেমান্টিক সার্চ |
| `GET` | `/api/dashboard/stats` | রিয়েলটাইম কেপিআই মেট্রিক্স ও সিস্টেম স্ট্যাটাস |
| `GET` | `/api/users` | ইউজার ও রোল ম্যানেজমেন্ট তালিকা |
| `POST` | `/api/users` | নতুন ইউজার তৈরি |
| `DELETE` | `/api/users/{id}` | ইউজার মুছে ফেলা |
| `GET` | `/api/models/list` | এলএলএম মডেল হাব ও কনফিগারেশন |
| `POST` | `/api/models/ping` | লাইভ সার্ভার রেসপন্স ল্যাটেন্সি টেস্ট (ms) |
| `GET` | `/api/settings` | কনফিগারেশন প্রদর্শন |
| `POST` | `/api/settings/test-connection` | এলএলএম সার্ভার সংযোগ পরীক্ষা |
